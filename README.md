# WireDraw ⚡ — 배선도 작성용 디자인 툴

브라우저에서 바로 동작하는 전기 **배선도(회로 배선도) 작성 도구**입니다.
별도의 설치·빌드 없이 `index.html`을 열기만 하면 됩니다. 데스크톱과
모바일(터치/핀치 줌) 모두 지원합니다.

## 실행 방법

가장 간단하게는 `index.html`을 브라우저로 열면 됩니다. 로컬 서버로
띄우려면:

```bash
# Python
python3 -m http.server 8000
# 그 후 http://localhost:8000 접속
```

## 주요 기능

- **부품 팔레트** — 전원(전지·DC·AC·접지), 수동소자(저항·커패시터·인덕터),
  스위치/퓨즈/버튼, 부하(램프·LED·모터·부저), 반도체(다이오드·트랜지스터),
  계측기(전압계·전류계), 커넥터/접속점 등. 검색창으로 빠르게 찾기.
- **배치** — 팔레트 항목을 캔버스로 **드래그**하거나 **클릭**해 추가.
- **배선** — `배선` 도구에서 단자(초록 점)를 다른 단자로 드래그하면
  자동 직교 라우팅으로 연결. 빈 공간에서 놓으면 자유 끝점 배선.
- **편집** — 선택·이동, 다중 선택(드래그 박스 / Shift+클릭), 회전(90°),
  복제, 삭제. 배선 꼭짓점은 드래그로 직접 조정 가능.
- **속성 패널** — 이름표(R1, SW1…), 값(330Ω, 9V…), 회전각, 심볼/배선 색상.
- **격자 스냅 / 줌 / 팬** — 그리드 스냅 토글, 휠·핀치 줌, 화면 맞춤.
- **실행 취소 / 다시 실행** — 최대 100단계.
- **저장 / 불러오기** — 브라우저 로컬 저장(자동 복원) + JSON 파일 입출력.
- **내보내기** — SVG · PNG · JSON.

## 단축키

| 키 | 동작 | 키 | 동작 |
|----|------|----|------|
| `V` | 선택 도구 | `W` | 배선 도구 |
| `H` / `Space` | 화면 이동 | `X` | 삭제 도구 |
| `R` | 90° 회전 | `Del` / `Backspace` | 삭제 |
| `Ctrl/⌘ + Z` | 실행 취소 | `Ctrl/⌘ + Shift + Z` / `Ctrl + Y` | 다시 실행 |
| `Ctrl/⌘ + D` | 복제 | `Ctrl/⌘ + S` | 저장 |
| `Esc` | 선택 해제 | | |

## 파일 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 화면 구조(툴바·팔레트·캔버스·속성·상태바) |
| `styles.css` | 다크 UI 테마 및 반응형 레이아웃 |
| `components.js` | 부품 심볼(SVG) 및 단자 정의 라이브러리 |
| `app.js` | 에디터 코어(렌더링·상호작용·저장·내보내기) |

## 부품 추가 방법

새 부품은 `components.js`에 항목 하나를 더하면 됩니다.

```js
myPart: {
  name: '이름', category: '분류', keywords: '검색 키워드',
  size: { w: 80, h: 24 },                 // 바운딩 박스
  terminals: [{ id: 'a', x: -40, y: 0 }], // 연결 단자(로컬 좌표)
  draw() { return `<svg 마크업...>`; }     // 심볼 본체
}
```

색상은 `var(--symbol)` / `var(--canvas-bg)` 변수를 사용하면 테마와
내보내기에서 자동으로 치환됩니다.
